# Mr Davies Portfolio

Responsive, buildless portfolio with Home, About, Projects, Contact and five individual project pages.

## Run locally

`python3 -m http.server 3000`

## Vercel

Import this repository. Framework: Other. No build command; output directory: repository root.

## Content

Content and portrait sourced from mr-davies.webflow.io. Contact uses the linked phone number on the previous Home and Projects pages. Project images are preserved from the background images on the previous portfolio. No project outcomes were invented. Contact form opens a mailto draft; it does not submit to a backend.

Scroll reveals replay on exit and entry and respect reduced-motion preferences.
